How to install.

Steps can vary slightly between phone models and Windows versions.

Android phone

  1. Open FLI on Google Play, or download the file for your language above.
  2. Install the keyboard app.
  3. Go to Settings › System › Languages & input › On-screen keyboard and switch the FLI keyboard on.
  4. In any app, tap the keyboard icon or globe key to switch to your language.

Windows PC

  1. Download the PC keyboard zip file for your language.
  2. Unzip it and run the installer inside.
  3. Open Settings › Time & language › Language & region and check the keyboard was added.
  4. Switch keyboards with Windows key + Space.
